# Dashboard CO2

Dashboard web para visualizar emisiones de CO2 y anomalías de temperatura.

## Tecnologías
- HTML
- CSS
- JavaScript
- Chart.js

## Ejecutar
Abrir con Live Server.


## Cambios realizados

- El dashboard pasó de ser estático a dinámico.
- Ahora consume datos climáticos en tiempo real.
- Muestra información meteorológica de Posadas.
- Incluye pronóstico de hasta 3 días.
