# Dashboard Climático

Dashboard web dinámico que muestra información meteorológica en tiempo real de Posadas utilizando una API externa.

## Funcionalidades

- Temperatura en tiempo real
- Humedad
- Velocidad del viento
- Pronóstico de 3 días
- Actualización dinámica desde API

## Tecnologías

- HTML
- CSS
- JavaScript
- Chart.js
- Open-Meteo API

## API utilizada

https://api.open-meteo.com/

## Ejecutar

Abrir con Live Server.
